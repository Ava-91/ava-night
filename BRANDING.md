# Ava Night branding

## Core idea

Ava Night's identity is **midnight calm with icy accents**.

The extension icon is intentionally monochrome: a black **A** combined with a crescent moon. The icon should remain simple and should not be recolored just to match the editor palette.

## Visual hierarchy

1. **Midnight surfaces** — `#0F1117`, `#131722`, `#151A24`
2. **Primary interaction** — `#61AFEF`
3. **Special/high-attention detail** — `#7FDBFF`
4. **Secondary structural accent** — `#B48EFA`
5. **Semantic values/states** — green, gold, and red

## Logo usage

- Keep the A + crescent mark monochrome when possible.
- Use generous empty space around the mark.
- Do not add gradients, glow effects, or unnecessary decorative elements to the logo.
- The editor palette should carry the color; the logo should carry the identity.

## Screenshot direction

Ava Night screenshots should make the same visual system recognizable across every preview:

- dark midnight editor background
- restrained blue/cyan UI accents
- readable code with semantic color roles
- minimal visual clutter
- consistent editor framing

The goal is not to make every screenshot look identical. The goal is to make every screenshot unmistakably belong to the same theme.

## Voice

Ava Night should sound calm, concise, and confident. Prefer language around **midnight, focus, quiet, clarity, balance, and long coding sessions** rather than exaggerated claims about performance or productivity.
