# 🌙 Ava Night

> *Where code meets the quiet of midnight.*

Ava Night is a carefully crafted Visual Studio Code theme for developers who prefer **calm over clutter**. Every color is chosen with intention to create a workspace that remains readable, elegant, and comfortable during long coding sessions.

## ✨ Highlights

- 🌌 Deep midnight-inspired interface
- 🎨 Carefully balanced syntax highlighting
- 🧠 Semantic token support
- 💻 Complete workbench styling
- 📂 Consistent Explorer, Search, Git, and Terminal colors
- 👀 Designed for extended coding sessions
- ⚡ Lightweight with zero runtime dependencies

## 🎨 Color Philosophy

> **Every color should communicate meaning—not compete for attention.**

Ava Night's visual identity is built around deep midnight surfaces, cool neutral text, blue interaction states, cyan highlights, and restrained semantic accents.

| Role | Hex |
| --- | --- |
| Deep background | `#0F1117` |
| Editor background | `#131722` |
| Panel background | `#151A24` |
| Borders | `#242C3A` |
| Primary text | `#D8DEE9` |
| Focus / primary accent | `#61AFEF` |
| Bright cyan | `#7FDBFF` |
| Secondary purple | `#B48EFA` |
| Success / added | `#98C379` |
| Warning / modified | `#FFD166` |
| Error / deleted | `#F07178` |

## 💡 Designed For

Ava Night is designed for and currently previewed/tested against TypeScript, React / TSX, JavaScript, CSS, JSON, Markdown, Git, the integrated terminal, and the VS Code workbench. Additional language validation is tracked in [Issue #2](https://github.com/Ava-91/ava-night/issues/2).

## 🚀 Installation

1. Open **Extensions** (`Ctrl + Shift + X`).
2. Search for **Ava Night**.
3. Click **Install**.
4. Select **Ava Night** from **Preferences → Color Theme**.

## 🛠 Development

```bash
git clone https://github.com/Ava-91/ava-night.git
cd ava-night
npm install
```

Press **F5** inside Visual Studio Code to launch an Extension Development Host and preview changes instantly.
